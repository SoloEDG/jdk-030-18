# 栈闩工房

机关推箱子纯前端工房。不同种类的箱子触发对应踏板，踏板改变门与地板，记录步数并保存已完成关卡的最佳成绩。

## 卷毯机制

部分关卡的地面铺着可沿格缝卷起的卷毯，毯由一格一条的条带组成：

- 站在毯端朝毯内按方向，整卷沿格缝逐排卷起；先碰到哪一排，就把那一排的地面、货、踏板、门一并卷进卷束。
- 站在卷束上按反方向即反向铺开。条带翻面后，夹持层的上下整体颠倒，原本压在下层的货会翻到顶层，箱子朝向（`facing`）随之翻转。
- 卷入中的格、货、踏板不再外露：不可通行、踏板断电、目标不计完成；只有真正外露并压在目标上的货才计入通关。
- 同一坐标可被多条条带反复卷铺，`depth` 记录最近反铺次序，被夹在两层之间的货绝不会画在顶层。
- 两条互相垂直的卷毯在交叉处可能卡住：拉这头若要先提起一段仍被另一卷压住的货，整次会停在最先受阻的那排，之前真正卷起的部分保留为半卷；挪开拦路货后可在卷束上沿原方向续卷。
- 侧栏「卷毯断面」可翻看每条条带自下而上的层叠与翻面状态。

## 本地运行

```bash
npm install
npm run dev
```

类型检查、生产构建与引擎模拟测试：

```bash
npm run typecheck
npm run build
npm test
```

## Docker

```bash
docker compose up --build
```
